# YoungSheep 横向超现实长卷原型

预览：`http://localhost:3000/world-door/index.html`

- 第一屏保持柔软时间原视觉：裂蛋、紫钟、小羊、三颗项目球、长影与门。
- 点击羊后，六个导航点沿影子出现：项目、关于、文章、Now、联系、快速了解。
- 门框持续微光，靠近后明显点亮；点击门后平滑进入同一张横向长卷。
- 第二场景已收紧为约 1.45 屏：抽屉羊位于左侧，右侧现实温室在水中形成 AI／机器人双重图像。
- 三个抽屉默认全部关闭；鼠标移入羊或聚焦羊后，整幅画平滑切换到三抽屉打开状态。
- 打开状态是一张完整插画，不使用 HTML 方框模拟抽屉；花、蓝色流体和彩色球都直接画在抽屉中。
- 打开后，三个抽屉区域分别进入花花系统、金融 AI 和 Skills 档案。
- 天空使用紫粉横向干刷，背景只保留旧纸纤维、普通墨点和稀疏横线。
- 空白处可左右拖动画布；滚轮不再强制转换成横向滚动。
- 所有内容在场景内弹层呈现；不进入空白内容页。
- 弹层包含完整介绍、能力拆解、标签和后续详情入口。

第二场景使用两张严格对齐的完整插画：`assets/surreal-exhibition-closed-v2.png` 与 `assets/surreal-exhibition-open-v2.png`。关闭图负责初始状态，打开图负责探索状态。
