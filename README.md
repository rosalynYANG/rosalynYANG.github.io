# YoungSheep · Creative & AI Lab

小样儿个人网站的稳定源码版本。网站包含横向探索首页，以及金融 AI、真实好花和 AI 文化导游项目案例。

## 本地运行

```bash
corepack enable
pnpm install --frozen-lockfile
pnpm dev
```

打开 `http://localhost:3000/world-door/index.html`。

## 生产构建

```bash
pnpm build
pnpm start
```

部署说明见 [DEPLOY_LINUX.md](./DEPLOY_LINUX.md)。
